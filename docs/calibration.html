Method · checking the measurements

Calibration agents

These are not real agents. Their behaviour is known in advance, so they show whether the arena measures correctly. A fake agent set to reply after 500 ms must be measured at 500 ms; the oracle, which is handed the script, must pass everything; the oracle that states wrong details must be caught.
