What the columns mean

Scenarios passed
A scenario passes when all of its checks pass and the agent replied to every caller turn. 'Untestable' means a check could not be applied, for example the agent never talked long enough to be interrupted.
Response delay
From the caller's last sound in a turn to the agent's first sound. Turns where the agent was already talking are left out.
Talked over a pause
Mid-thought pauses in which the agent started speaking before the caller had finished.
Stopped when interrupted
Interruptions after which the agent went quiet within the allowed time.
Time to stop
From the start of the caller's interruption to the agent going quiet.
Dealt with the interruption
The reply after an interruption mentions what the caller interrupted about.
Kept talking through 'hmm'
Filler words during the agent's speech that did not make it stop.
Details read back right
Numbers, dates and similar details found correctly in a transcript of the reply.
Replied in caller's language
Calls where the reply was in the caller's language. A Hinglish caller should get Hindi or Hinglish, not pure English.
Turns with no reply
Caller turns the agent never answered within the time allowed.
